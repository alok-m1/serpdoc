## Overview

SERPDoc is the official documentation website for the **SERPHouse API**.

It contains everything developers need to integrate SERPHouse into their applications, including:

- Complete REST API documentation
- Interactive examples
- Official SDKs
- AI framework integrations
- MCP Server setup
- Agent development guides
- Deployment examples
- Authentication guides
- Search playground

# Getting Started

## Installation

```bash
git clone https://github.com/SERPHouse/serpdoc.git

cd serpdoc

npm install
```

---

## Development

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## Production

```bash
npm run build

npm start
```
