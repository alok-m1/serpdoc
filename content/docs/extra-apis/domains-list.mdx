Get the full list of supported domains by our SERP API. This list also contains Bing and Yahoo domains.

<Callout type="warn">
  Requires authentication → provide your API key as a Bearer token in the
  Authorization header.
</Callout>

## Get a List of Domains

`GET` `https://api.serphouse.com/domain/list`

### Headers

| Name                                                 | Type   | Description             |
| ---------------------------------------------------- | ------ | ----------------------- |
| Authorization <span style={{color: "red"}}>\*</span> | String | Bearer `<YOUR_API_KEY>` |

<Callout type="info">
  Returns a JSON object with a `results` array containing all supported domain
  strings for Google, Bing, and Yahoo.
</Callout>
