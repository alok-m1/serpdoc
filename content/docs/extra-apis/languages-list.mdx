Retrieve the full list of languages by Google, Bing, and Yahoo. You can use the language code in performing SERP requests.

<Callout type="warn">
  Requires authentication — provide your API key as a Bearer token in the Authorization header.
</Callout>

## Get a Full List of Languages

`GET` `https://api.serphouse.com/language/list/{type}`

### Path Parameters

| Name | Type | Description |
|------|------|-------------|
| type | String | `google`, `bing`, or `yahoo` |

### Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization | String | Bearer `<YOUR_API_KEY>` |
