---
title: Check SERP Status
description: Check the processing status of a scheduled SERP task by its unique ID.
---

As a response of the API server, you will get a status of your SERP task.

<Callout type="warn">
  Requires authentication → provide your API key as a Bearer token in the Authorization header.
</Callout>

## Get a Status of Your SERP Task

`GET` `https://api.serphouse.com/serp/check`

### Query Parameters

| Name | Type | Description |
|------|------|-------------|
| id <span style={{color: "red"}}>*</span> | String | Unique identifier of your SERP task |

### Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization <span style={{color: "red"}}>*</span> | String | Bearer `<YOUR_API_KEY>` |

## Example Request

<ApiExample
  endpoint="https://api.serphouse.com/serp/check"
  method="GET"
  params='{"id": "77224195"}'
/>

## Example Response

<ApiExample
  mode="response"
  response={{ status: "success", msg: "Completed", results: "" }}
