---
title: Get SERP Result
description: Retrieve the results of a previously scheduled SERP task by its unique ID.
---

import { getSerpResultJsonResponse } from "@/lib/api-examples/getSerpResult";

As a response of the API server, you will receive a JSON array containing the result of your SERP query.

<Callout type="warn">
  Requires authentication → provide your API key as a Bearer token in the
  Authorization header.
</Callout>

`GET` `https://api.serphouse.com/serp/get`

## Get SERP Result

### Query Parameters

| Name                                      | Type   | Description                         |
| ----------------------------------------- | ------ | ----------------------------------- |
| id <span style={{color: "red"}}>\*</span> | String | Unique identifier of your SERP task |

### Headers

| Name                                                 | Type   | Description             |
| ---------------------------------------------------- | ------ | ----------------------- |
| Authorization <span style={{color: "red"}}>\*</span> | String | Bearer `<YOUR_API_KEY>` |
