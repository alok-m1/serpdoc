---
title: Get SERP Result

import { getSerpResultResponse } from '@/lib/api-examples/getSerpResult';

As a response of the API server, you will receive a JSON array containing the result of your SERP query.

<Callout type="warn">
  Requires authentication → provide your API key as a Bearer token in the Authorization header.
</Callout>

`GET` `https://api.serphouse.com/serp/get`

## Get SERP Result

### Path Parameters

| Name | Type | Description |
|------|------|-------------|
| responseType | String | `html` or `json` |

### Query Parameters

| Name | Type | Description |
|------|------|-------------|
| id | String | Unique identifier of your SERP task |

### Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization | String | Bearer `<YOUR_API_KEY>` |
