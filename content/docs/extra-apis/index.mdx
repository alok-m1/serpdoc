Extra APIs cover live and scheduled SERP workflows, account details, and lookup helpers for domains, languages, and locations. Use these alongside the Google, Bing, and Yahoo search endpoints.

All endpoints require authentication — pass your API key as a Bearer token in the `Authorization` header.
