Retrieve your account information, including active plan, credit usage information and more.

> **Requires authentication**

## Get Account Information

`GET` `https://api.serphouse.com/account/info`

### Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization | String | Bearer `<YOUR_API_KEY>` |

### Response

Returns account details including email, name, API key, and plan information with credit totals.

### Example Request

```bash
curl --location --request GET 'https://api.serphouse.com/account/info' \
--header 'Authorization: Bearer <YOUR_API_KEY>'
```
