Smithery is a platform that simplifies MCP server installation and management.

<Callout type="info">
  View on Smithery: <a href="https://smithery.ai/servers/serphouse/serphouse-mcp">serphouse/serphouse-mcp</a>
</Callout>

## Installation

```bash
npx -y @smithery/cli install serphouse/serphouse-mcp --client claude
```

<Callout type="success">
  Replace <code>--client claude</code> with your preferred AI client — Smithery supports Claude Code, Cursor, VS Code, and more.
</Callout>

## Alternative Installation

You can also connect directly using the hosted MCP endpoint:

```
https://mcp.serphouse.com/YOUR_SERPHouse_API_KEY/mcp
```

<Callout type="warn">
  Replace <code>YOUR_SERPHouse_API_KEY</code> with your actual SERPHouse API key.
</Callout>

## Troubleshooting

| Issue | Solution |
|-------|----------|
| **npx not found** | Ensure Node.js is installed. |
| **401 Unauthorized** | Verify your API key is valid and active in your [dashboard](https://serphouse.com). |
| **Server not detected** | Restart your AI client after installation. |
