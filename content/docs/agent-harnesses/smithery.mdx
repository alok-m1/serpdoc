Smithery is a platform that simplifies MCP server installation and management.

**View on Smithery:** [serphouse/serphouse-mcp](https://smithery.ai/servers/serphouse/serphouse-mcp)

## Installation

```bash
npx -y @smithery/cli install serphouse/serphouse-mcp --client claude
```

## Supported Clients

Install for any supported AI client using the `--client` option.

## Alternative Installation

You can also connect directly using the hosted MCP endpoint:

```
https://mcp.serphouse.com/YOUR_SERPHouse_API_KEY/mcp
```

## Troubleshooting

- Ensure Node.js is installed (npx requires Node.js)
- Verify your API key is valid
- Restart your AI client after installation
