Fetch real-time image search results from Yahoo, enabling seamless access to images from a wide range of online sources.

> **Requires authentication**

`POST` `https://api.serphouse.com/yahoo-image`

## Path Parameters

| Name | Type | Description |
|------|------|-------------|
| responseType | String | `html` or `json` |

## Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization | String | Bearer `<YOUR_API_KEY>` |
| Content-Type | String | application/json |

## Request Body

| Name | Type | Description |
|------|------|-------------|
| q | string | Search phrase |
| domain | string | Yahoo domain (e.g. `in.yahoo.com`). Use domains list API. |
| lang | string | Language code e.g. `lang_en`, `lang_fr` |
| page | integer | Page number |
| no_trace | string \| integer | Enterprise only. Enables NoTrace mode. |

## Example Request

```bash
curl --location --request POST 'https://api.serphouse.com/yahoo-image' \
--header 'Authorization: Bearer <YOUR_API_KEY>' \
--header 'Content-Type: application/json' \
--data-raw '{
    "data": {
        "q": "naredra modi",
        "domain": "in.yahoo.com",
        "lang": "lang_en" 
    }
}'
```
