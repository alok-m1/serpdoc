---
title: Yahoo News API
description: Access real-time Yahoo News search results with the latest headlines and breaking stories.
---

Retrieve real-time news results from the Yahoo News search page, providing access to the latest headlines, breaking news, and stories from trusted publishers.

> **Requires authentication**

`POST` `https://api.serphouse.com/yahoo-news`

## Path Parameters

| Name | Type | Description |
|------|------|-------------|
| responseType | String | `html` or `json` |

## Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization | String | Bearer `<YOUR_API_KEY>` |
| Content-Type | String | application/json |

## Request Body

| Name | Type | Description |
|------|------|-------------|
| q | string | Search phrase |
| domain | string | Yahoo domain (e.g. `in.yahoo.com`). Use domains list API. |
| lang | string | Language code e.g. `lang_en`, `lang_fr` |
| device | string | `desktop` or `mobile` |
| page | integer | Page number |
| no_trace | string \| integer | Enterprise only. Enables NoTrace mode. |

## Example Request

```bash
curl --location --request POST 'https://api.serphouse.com/yahoo-news' \
--header 'Authorization: Bearer <YOUR_API_KEY>' \
--header 'Content-Type: application/json' \
--data-raw '{
    "data": {
        "q": "football world cup 2026",
        "domain": "in.yahoo.com",
        "lang": "lang_en", 
        "device": "desktop"
    }
}'
```
