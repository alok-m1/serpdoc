Retrieve real-time search results from the Yahoo search page, providing access to relevant websites, search listings, and web content.

<Callout type="warn">
  Requires authentication — provide your API key as a Bearer token in the Authorization header.
</Callout>

`POST` `https://api.serphouse.com/yahoo-web`

## Path Parameters

| Name | Type | Description |
|------|------|-------------|
| responseType | String | `html` or `json` |

## Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization | String | Bearer `<YOUR_API_KEY>` |
| Content-Type | String | application/json |

## Request Body

| Name | Type | Description |
|------|------|-------------|
| q | string | Search phrase |
| domain | string | Yahoo domain (e.g. `fr.yahoo.com`). Use domains list API. |
| lang | string | Language code e.g. `lang_en`, `lang_fr` |
| device | string | `desktop` or `mobile` |
| page | integer | Page number |
| no_trace | string \| integer | Enterprise only. Enables NoTrace mode. |

<Callout type="info">
  Yahoo requires regional domains — use <code>serphouse_domain_list</code> to find the right domain for your target region. <code>yahoo.com</code> is not valid.
</Callout>
