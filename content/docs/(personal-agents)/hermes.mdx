[Hermes Agent](https://hermes-agent.nousresearch.com) is the open-source, self-improving AI agent built by [Nous Research](https://nousresearch.com). It runs anywhere, remembers across sessions, and connects to 20+ messaging platforms. By adding the SERPHouse MCP Server to Hermes, your personal agent gains live Google, Bing, and Yahoo search across every platform you use it on.

  — zero extra infrastructure to run.

## What You'll Build

| Capability          | How it works                                                               |
| ------------------- | -------------------------------------------------------------------------- |
| **Live web search** | Hermes calls `mcp_serphouse_search` for fresh Google results on demand     |
| **News & media**    | Google / Bing / Yahoo news, images, and videos from any connected platform |
| **Rank tracking**   | Ask about your position for any keyword, engine, and location              |
| **Daily briefings** | Cron-scheduled SERPHouse searches delivered to Telegram, Discord, and more |

## Prerequisites

- An active **SERPHouse account** — free credits included on signup
- A **SERPHouse API key** from your [dashboard](https://serphouse.com)
- A machine with **Bash** and **network access** to install Hermes

<Callout type="info">
  Hermes supports macOS and Linux. Windows users can use WSL2.
</Callout>

## Step 1 — Get Your SERPHouse API Key

<Steps>
  <Step>
    Sign up at [serphouse.com](https://serphouse.com) and confirm your email.
  </Step>
  <Step>Open your **Dashboard** and copy the **API key** shown there.</Step>
  <Step>
    Keep it somewhere safe — you'll paste it into the Hermes config next.
  </Step>
</Steps>

<Callout type="error" title="Keep your key secure">
  Your API key maps directly to your credit usage. Never commit it to a
  repository, share it in public channels, or paste it into a screenshot.
</Callout>

## Step 2 — Install Hermes

Install the latest Hermes Agent with the official script:

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

<Steps>
  <Step>
    Run the installer above in your terminal.
  </Step>
  <Step>
    Follow the on-screen prompts to pick your model provider and set your API key.
  </Step>
  <Step>
    Confirm the CLI is available:

    ```bash
    hermes --version
    ```

  </Step>
</Steps>

<Callout type="info" title="Prefer a guided setup?">
  The installer accepts flags like <code>--yes</code> for unattended installs.
  Run{" "}
  <code>
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash -- --help
  </code>{" "}
  to see every option.
</Callout>

## Step 3 — Add the SERPHouse MCP Server

MCP servers are declared in `~/.hermes/config.yaml` under `mcp_servers`. Open the file and add the SERPHouse hosted endpoint:

```yaml
mcp_servers:
  serphouse:
    url: "https://mcp.serphouse.com/YOUR_SERPHouse_API_KEY/mcp"
```

<Callout type="info">
  Replace <code>YOUR_SERPHouse_API_KEY</code> with your actual SERPHouse API
  key. The key is forwarded to the SERPHouse API as a Bearer token.
</Callout>

## Step 4 — Start (or Restart) Hermes

```bash
hermes chat
```

<Callout type="success" title="Tools auto-register">
  SERPHouse tools are discovered and registered automatically at startup. Tools
  appear as <code>mcp_serphouse_*</code>, for example{" "}
  <code>mcp_serphouse_search</code>.
</Callout>

## Step 5 — Verify the Server

To confirm the server is reachable before using it, reload the MCP config inside a session:

```
/reload-mcp
```

Any connection error will be reported immediately.

<Steps>
  <Step>
    Type <code>/reload-mcp</code> in the chat session.
  </Step>
  <Step>
    Watch for a confirmation that <code>serphouse</code> connected with no
    errors.
  </Step>
  <Step>Ask your first search query — see below.</Step>
</Steps>

<Callout type="info" title="Tune the tool surface">
  You can narrow the tool surface at any time by editing the server entry — see
  the [Hermes MCP
  docs](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp).
</Callout>

## Scheduling Searches

Hermes has built-in cron. Combine it with SERPHouse for daily briefings delivered to any connected platform:

```
/cron add "0 7 * * *" "Search Google News for 'AI SEO' and send a summary here."
```

<Callout type="idea" title="Make it yours">
  Swap the time, query, or channel in the cron expression to fit your routine —
  e.g. a Monday-morning competitor digest or a Friday industry roundup.
</Callout>

## Troubleshooting

| Issue                   | Solution                                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------------------- |
| **Server doesn't load** | Verify the entry is valid YAML under `mcp_servers` and restart Hermes.                               |
| **401 Unauthorized**    | Verify your API key is valid and active in your [dashboard](https://serphouse.com).                  |
| **Tools not appearing** | Run `/reload-mcp` or restart Hermes; then ask for a search.                                          |
| **Credits exhausted**   | Check your account credit balance in the SERPHouse dashboard.                                        |
| **Yahoo search fails**  | Call the domain list tool first — `yahoo.com` is invalid; use a regional domain like `uk.yahoo.com`. |

<Callout type="info" title="Still stuck?">
  Most issues are fixed by re-verifying your API key, credit balance, and the
  endpoint URL. If it persists, contact [SERPHouse
  support](https://serphouse.com) at
  [getsupport@serphouse.com](mailto:getsupport@serphouse.com).
</Callout>
