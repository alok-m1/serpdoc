Get up-to-date Google Shopping results, including product details and pricing information, with the Google Shopping API endpoint.

<Callout type="warn">
  Requires authentication → provide your API key as a Bearer token in the Authorization header.
</Callout>

`POST` `https://api.serphouse.com/google-shop`

## Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization | String | Bearer `<YOUR_API_KEY>` |
| Content-Type | String | application/json |

## Request Body

| Name | Type | Description |
|------|------|-------------|
| q | string | Search phrase |
| domain | string | Choose google domain |
| lang | string | Language code e.g. `en`, `fr` |
| loc | string | Optional if specifying `loc_id` |
| loc_id | integer | Optional if specifying `loc` |
| page | integer | Page number |
| no_trace | string \| integer | Enterprise only. Enables NoTrace mode. |
