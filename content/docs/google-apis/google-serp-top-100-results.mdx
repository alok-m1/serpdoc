<Callout type="idea" title="Why this endpoint?">
  Google recently restricted the `num` parameter to a maximum of 10 results per request. To overcome this limitation, we introduced a new endpoint that can fetch results from multiple pages.
</Callout>

## How It Works

- **`max_pages`** defines how many result pages you want scraped.
- Each page contains up to 10 results.
- `max_pages=5` → up to 50 results (5 pages × 10 results per page)
- `max_pages=10` → up to 100 results (10 pages × 10 results per page)

## Pricing

<Callout type="success">
  The cost is based on the number of pages scraped. **1 page = 10 credits**.
</Callout>

- `max_pages=7` → 7 pages scraped → costs 70 credits
- If `max_pages` is set to 7 but only 2 pages are available, 20 credits are charged.

<Callout type="warn">
  Requires authentication — provide your API key as a Bearer token in the Authorization header.
</Callout>

`POST` `https://api.serphouse.com/serp/google_advanced`

## Path Parameters

| Name | Type | Description |
|------|------|-------------|
| responseType | String | `html` or `json` |

## Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization | String | Bearer `<YOUR_API_KEY>` |
| Content-Type | String | application/json |

## Request Body

| Name | Type | Description |
|------|------|-------------|
| q | string | Search phrase |
| domain | string | Google domain |
| lang | string | Language code e.g. `en`, `fr` |
| device | string | `desktop` or `mobile` |
| loc | string | Optional if specifying `loc_id` |
| loc_id | integer | Optional if specifying `loc` |
| verbatim | integer | Google Verbatim (`0` or `1`) |
| gfilter | integer | Filter on/off (`1` or `0`) |
| max_pages | integer | Pages to return (1–10, default 10) |
| date_range | String | Date filter |
