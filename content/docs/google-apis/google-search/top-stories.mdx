Retrieve the latest breaking news and headline stories directly from Google search results using the Top Stories result type.

<Callout type="warn">
  Requires authentication → provide your API key as a Bearer token in the Authorization header.
</Callout>

`POST` `https://api.serphouse.com/google-web`

## Response

Top Stories appear in the `top_stories` field within the response results. Each entry contains the article title, publisher, timestamp, snippet, and thumbnail.

| Field | Type | Description |
|-------|------|-------------|
| top_stories | array | Array of news story entries |
| title | string | Headline of the news article |
| channel | string | Publisher name |
| time | string | Publication time description |
| snippet | string | Article summary |
| url | string | Link to the full article |
| img | string | Thumbnail image (base64) |
