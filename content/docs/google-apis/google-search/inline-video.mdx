Access Google video results embedded within web search responses, surfacing relevant video content from YouTube and other sources.

<Callout type="warn">
  Requires authentication → provide your API key as a Bearer token in the Authorization header.
</Callout>

`POST` `https://api.serphouse.com/google-web`

## Response

Inline videos appear in the `inline_videos` field within the response results. Each entry contains video metadata, thumbnail, and source details.

| Field | Type | Description |
|-------|------|-------------|
| inline_videos | array | Array of inline video results |
| title | string | Video title |
| link | string | URL to the video |
| channel | string | Publisher or channel name |
| thumbnail | string | Video thumbnail image (base64) |
| duration | string | Video length |
