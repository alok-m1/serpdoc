Access Google's horizontal carousel results that showcase media, events, or entities in an interactive scrollable format within search results.

<Callout type="warn">
  Requires authentication → provide your API key as a Bearer token in the
  Authorization header.
</Callout>

`POST` `https://api.serphouse.com/google-web`

## Response

Carousel results appear in the `carousel` field within the response results. Each entry contains a carousel item with title, link, and image.

| Field     | Type    | Description                    |
| --------- | ------- | ------------------------------ |
| carousel  | array   | Array of carousel item entries |
| position  | integer | Position in the carousel       |
| title     | string  | Item title                     |
| link      | string  | Google search URL for the item |
| image_url | string  | Item thumbnail image           |
