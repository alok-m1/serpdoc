Access Twitter/X results that appear in Google search results, surfacing relevant tweets and social media content.

<Callout type="warn">
  Requires authentication — provide your API key as a Bearer token in the Authorization header.
</Callout>

`POST` `https://api.serphouse.com/google-web`

## Response

Twitter results appear in the `twitter` or `tweets` field within the response results. Each entry contains tweet details, author, and engagement data.

| Field | Type | Description |
|-------|------|-------------|
| twitter | array | Array of tweet entries |
| position | integer | Ranking position |
| title | string | Tweet text or title |
| link | string | URL to the tweet |
| author | string | Twitter/X account name |
| snippet | string | Tweet content preview |
