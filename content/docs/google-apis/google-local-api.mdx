---
title: Google Local API
description: Structured local business results from Google Search including ratings, reviews, and addresses.
---

Google Local API provides structured local business results from Google Search, including position, business name, rating, reviews count, address, GPS coordinates, service options, and direct map navigation links.

<Callout type="warn">
  Requires authentication — provide your API key as a Bearer token in the Authorization header.
</Callout>

`POST` `https://api.serphouse.com/google-local-api`

## Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization | String | Bearer `<YOUR_API_KEY>` |
| Content-Type | String | application/json |

## Request Body

| Name | Type | Description |
|------|------|-------------|
| q | string | Search phrase |
| domain | string | Choose google domain |
| lang | string | Language code e.g. `en`, `fr` |
| loc | string | Optional if specifying `loc_id` |
| loc_id | integer | Optional if specifying `loc` |
| page | integer | Page number (up to 20 local results per page) |
