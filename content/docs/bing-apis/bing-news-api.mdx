Access real-time Bing News search results and stay informed with the latest news articles, headlines, and trending stories from trusted sources across the web.

> **Requires authentication**

`POST` `https://api.serphouse.com/bing-news`

## Path Parameters

| Name | Type | Description |
|------|------|-------------|
| responseType | String | `html` or `json` |

## Headers

| Name | Type | Description |
|------|------|-------------|
| Authorization | String | Bearer `<YOUR_API_KEY>` |
| Content-Type | String | application/json |

## Request Body

| Name | Type | Description |
|------|------|-------------|
| q | string | Search phrase |
| lang | string | Language code e.g. `en-US`, `fr-FR` |
| device | string | `desktop` or `mobile` |
| loc | string | Optional if specifying `loc_id` |
| loc_id | integer | Optional if specifying `loc` |
| page | integer | Page number |
| no_trace | string \| integer | Enterprise only. Enables NoTrace mode. |

## Example Request

```bash
curl --location --request POST 'https://api.serphouse.com/bing-news' \
--header 'Authorization: Bearer <YOUR_API_KEY>' \
--header 'Content-Type: application/json' \
--data-raw '{
    "data": {
        "q": "today top news",
        "lang": "en-IN", 
        "device": "desktop",
        "loc": "Surat,Gujarat,India"
    }
}'
```
